## 4. 这不等于可以做 STOCK LP

六项证据补齐只意味着**终闸的输入不再缺失**，不意味着结论为正。仍未满足：

| 门槛 | 现状 |
|---|---|
| Stage A ≥72h 且覆盖率 ≥99% | **9h / 覆盖率 90.8%**（漂移已修，正在回升） |
| Stage B ≥14 天且覆盖一个周末 | **未开始** |
| `capital_policy_pass` | `CAPITAL_POLICY_CONFLICT` 未解（100U 下 CORE 上限 42.5U < 旧单仓 50U） |
| `usable_provider_count ≥ 2` | **=1**，LIVE 闸按 §8.3 保持 BLOCKED |
| 有机成交量验证 | 未做，PRD §10.3 要求区分 raw 与 organic |
| 参考价与 DEX 的持续偏离监控 | 仅有单点快照（6 组溢价），无时间序列 |

另外，`in-range` 时长折算仍未实现——当前 fee-growth 是**全区间上界**，集中流动性头寸的真实收益需按价格落在区间内的时长折算。这是 STOCK 策略进入 Shadow 前必须补的最后一块。
