    sendTransaction, LBBOT_CONFIRM_LIVE, and the action verbs
    mint / addLiquidity / removeLiquidity / approve / swap / bridge.
    Also requires positive evidence (shadow mode banner, metrics
    server start line). Exits 0 on clean smoke, 1 on any violation.
