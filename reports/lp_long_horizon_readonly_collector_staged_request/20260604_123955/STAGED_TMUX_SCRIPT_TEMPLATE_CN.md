## 6. tmux session 数量限制

任何时间点, **最多 1 个** tmux session 跑 LP long horizon collector.
多 session 启动会触发 safety self_check fail + abort.

监控命令:

```bash
tmux ls | grep "lp_long_horizon" | wc -l  # 期望 <= 1
```
