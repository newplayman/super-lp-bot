# TIER_BC_DEFINITION

## Tier B
- 中等 TVL
- 中高 volume / TVL
- 中高 fee APR
- exit depth 可接受
- holder concentration 可接受
- trader concentration 不极端
- 比 Tier A 更有收益潜力
- 比 Tier C 更可退出
- Tier B 是当前小资金 LP 主研究方向

## Tier C
- 小 TVL / 高 fee / 高 volatility / 高 tail risk
- 只作为严格 watchlist / rediscovery / counterfactual 研究
- 不允许直接进入 micro candidate，除非通过 hard rejection policy

- proof unit = position_lifecycle
- decision_trace 不允许作为 primary proof
- tiny_canary_allowed = no
