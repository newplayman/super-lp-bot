## 修复总览（按审计 §12 三包）

### 第一包：资金与持仓生命周期

- **R2-01**：把 `compute_full_cost_nav` + `compute_liquidation_nav` 接入 runner（替换 `compute_nav` 调用；写 marks 用新 NAV）
- **R2-02**：在真正 grant 且 inventory 输入有效的同一时点创建持仓、冻结区间、设置 fee-growth 基线。grant 前不写 marks。**统一"开仓生命周期"**
- **R2-03**：`_copy_new_rows` 拒绝 BROADCAST_UNKNOWN → RELEASED/EXPIRED 状态迁移；仅允许带 nonce/收据/链上状态核验的迁移路径
- **R2-09**：`compute_liquidation_nav` 必须复用 `inventory_for_position()` 已有模块；明确 raw/human liquidity、raw/human price、固定上下界、fee-growth 增量/基线和 USD 报价的单位契约

### 第二包：数据与毕业

- **R2-04**：`_build_state` 传入 8 项新参数；`stage_b_status` 接收**从真正策略窗口计算**的 `effective_days_covered`（不再用采集跨度）；整日统一用 86400 秒分母；首尾不足整日单列
- **R2-05**：`audit_unexplained_ledger_diffs` **只读本轮原始证据**（rh_journal 借贷/持仓/费用核验），**不读历史 reconciliation_runs**；毕业证据选择器**单独建立**，绑定 profile、代码/模型版本、资本政策、冻结窗口
- **R2-06**：池态陈旧/未来时，**拒绝新增模拟仓位**（不只是追加 reasons）。pool as-of / liquidity / tick state / fees / 报价 **统一时点绑定**到样本
- **R2-07**：`full_test=None` / 解析失败 / 零测试 / 缺必需故障场景 / 错版本 / dirty 全部阻断 VALIDATED；`--skip-tests` 只能产出观察报告，不能 VALIDATED
